# Capture Decision

## Definitions

**Meaningful** information materially improves understanding, a decision, an action, a deliverable, an operating process, or future work. It is more than a passing mention, acknowledgement, duplicate, or unsupported thought.

**Durable** information is likely to remain useful beyond the current exchange or can be reliably maintained as circumstances change. It has a clear owner or subject, enough context to interpret later, and a suitable authoritative home.

## Update An Existing Record

Update a suitable existing record when the new information adds or changes at least one material fact, decision, source, conclusion, instruction, status, relationship, risk, or next action.

Do not update it for wording-only repetition, incidental mentions, raw logs, or information already represented accurately.

## Create A New Record

Create a new record only when all of these gates pass:

- **Lasting value:** the information is meaningful and durable.
- **Clear ownership:** it has an identifiable subject, initiative, decision, process, or other record owner.
- **Useful substance:** supported content and context make the record useful on its own; it is not an empty placeholder.
- **No suitable home:** no existing authoritative record can absorb it without mixing different purposes or owners.

These are mandatory gates, not optional questions. If any gate fails, do not create a new record. Keep the finding in the current output, update a suitable record if justified, or record a controlled-backlog gap.

## Analysis-Only Work

Analysis may produce useful findings without authorizing a durable write. When the work boundary is read-only, provide the findings in chat or a clearly marked draft. Publish later only when authorized.
